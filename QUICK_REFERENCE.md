# DevOps Panel - Quick Reference Card

## 🚀 Quick Start

### 1. Connect Vercel
```
Settings → Integrations → Vercel Integration → Connect Vercel
```

### 2. Open DevOps Panel
```
Dashboard → DevOps Panel
```

### 3. Select Project
```
Filter Bar → Select Project from Dropdown
```

### 4. View Analysis
```
Overview Tab → See Project Analysis Card
```

## 🎯 Common Tasks

### View Project Analysis
1. Select project from filter
2. Look at Overview tab
3. See analysis card

### View Deployments
1. Go to Deployments tab
2. Select project
3. See deployment list

### View Build Logs
1. Go to Deployments tab
2. Click "Logs" on deployment
3. See build output

### Refresh Data
1. Click Refresh button
2. Wait for reload
3. See updated data

### Compare Projects
1. Select first project
2. Note statistics
3. Select another project
4. Compare stats
