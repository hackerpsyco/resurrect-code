## 🎯 Workflow

1. **User connects Gemini API** in Settings
2. **User selects GitHub repository** from their account
3. **User selects Vercel project** to link
4. **Click "Analyze Code"**:
   - Fetches code files from GitHub (20%)
   - Analyzes with Gemini AI (40%)
   - Returns results with priority breakdown (100%)
5. **Click "Generate Improvements"**:
   - Generates improved code for each issue
   - Shows progress as improvements are created
6. **Click "Push to GitHub"**:
   - Creates new branch `ai-improvements-{timestamp}`
   - Creates pull request with analysis summary
   - Links to GitHub PR

## 📝 How to Use

### 1. Connect Gemini
- Go to Settings → Gemini Integration
- Get API key from Google AI Studio
- Click "Connect"

### 2. Use Automation Tab
- Open DevOps Panel → Automation tab
- Select GitHub repository
- Select Vercel project
- Click "Analyze Code"
- Wait for analysis to complete
- Click "Generate Improvements"
- Click "Push to GitHub"

### 3. Review PR
- GitHub PR is created automatically
- Review changes in PR
- Merge when ready
